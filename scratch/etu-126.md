## Design

Extend existing Experiment.jobs and manabot deploy with a serial cohort owner.
Frozen cohort binds compiled plans, original authoring receipts, case/seed order,
absolute deadline, total dollars, prior charges and controller cost reserve.
S3 owns cohort intent/control/state and existing per-job identity/creation fences.
OS service (launchd/systemd) owns process lifetime on an explicitly selected host;
local flock plus immutable S3 host/directory binding excludes concurrent owners.
No expiring distributed lease or automatic host takeover: a lost owner disk/host
requires explicit recovery, not a potentially concurrent replacement.

Persist each Job identity and original deadline before submission. Restart reads
provider/record/artifact references before taking action. Ambiguous create never
uses a new ID. Transient reads retry; failed/paused/cancelled/missing attempts stop
further jobs. Reserve every job's full spending limit plus prior/control costs;
reconcile observed deletion costs once and refuse further admission on overrun.
No numerical/scientific retry policy is inferred. CUDA checkpoint export is not
exact process recovery. Cohort cancellation is sticky and reaches the active job.
Scheduling never fetches model bundles or depends on W&B/report availability.

Delete — do not maintain: no repository deletion target. Retain frozen historical
controller as evidence; ordinary callers move to the shared deploy cohort path.
